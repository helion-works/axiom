Documented MCP Vulnerabilities and Attack Demonstrations

Three published CVEs, one bug disclosed by a vendor and two demonstrations by security researchers. Each entry links to its source.

CVE · Critical
CVE-2025-6514: mcp-remote command injection
A malicious MCP server could run commands on the client machine through a crafted OAuth authorization endpoint. Versions 0.0.5 to 0.1.15; fixed in 0.1.16. Source: JFrog
CVE · Critical
CVE-2025-49596: MCP Inspector remote code execution
Versions below 0.14.1 had no authentication between the Inspector client and its proxy, so unauthenticated requests could launch MCP commands. Fixed in 0.14.1. Source: GitHub advisory
CVE · High
CVE-2025-53109: Filesystem MCP server symlink bypass
Symlinks inside an allowed directory could give access to files outside it. Affects every version up to 0.6.2, and 2025.1.14 to before 2025.7.1; fixed in 2025.7.1. Source: GitHub advisory
Disclosed bug
Asana MCP server data exposure
A bug could have exposed one organization's data to MCP users in another. Asana took the server offline from 5 to 17 June 2025. The report found no indication that it was exploited. Source: The Register
Demonstration
WhatsApp MCP: tool poisoning
Researchers showed that a second MCP server offering a harmless "fact of the day" tool could later change its description and make an agent send the user's WhatsApp chat history to an attacker. Source: Invariant Labs
Demonstration
GitHub MCP: prompt injection through an issue
Researchers showed that a malicious issue in a public repository could make an agent copy data from the user's private repositories into a public pull request. They describe it as a design problem in agent systems, not a bug in the server's code. Source: Invariant Labs
